# CLAUDE.md

Architect's Toolbox is a client-side Minecraft mod for measuring, counting and visualising block selections, with shape modes, a clipboard and ghost block previews.

This branch (`rebuild-2.0`) is the 2.0.0 rebuild. The spec is `plan/projects/Architects_Toolbox/features.md` in the kit and the steps are in its `backlog.md`. 1.0.0 stays on `master` and the `1.21.1`/`1.21.10` branches as the reference.

Mod id `architects_toolbox`; package `com.ArchitectsToolbox`. The key `key.architects_toolbox.measure`, its category `architects_toolbox:main` and `config/architects_toolbox.json` keep the names 1.0.0 gave them.
